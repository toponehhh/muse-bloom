# Editorial Studio · v1.2.0

2026-10-19：把 Muse Bloom 调整为成熟的时尚画册风格，以服装、角色与个人作品为中心。视觉方向是暖白、墨黑、酒红、香槟色，配合杂志排版和摄影棚柔光。首页、试衣间、章节、衣橱、结算、弹窗、作品相册、导出图片和宣传素材使用同一套语言。

## 这次的设计选择

- Georgia 衬线大标题与本地 Segoe UI 操作文字形成层次；首页使用双造型画册构图，章节用期刊式编号。
- 减少糖果色、气泡、贴纸、表情符号和大圆角。衣橱保留清晰的分类图标、选中边框、标签及完成度。
- 墨黑主按钮统一关键操作；酒红色标记当前分类与选中物品。正文和操作提示比装饰性说明更深，保证可读性。
- 试衣间使用暖灰摄影棚、直线画框、柔光和少量星芒；装饰不拦截输入，减少动态效果时停止动画。
- 手机保留单行品牌和主要工具；试衣间上下分区，衣橱内部滚动，提交按钮保持可见。首页标题与说明显式断行，避免句子挤在一起。

这是本项目的具体设计判断。竞品参考来自 CrazyGames 的换装品类页面与公开介绍，重点借鉴主题挑战、评分奖励、衣橱解锁和作品回看的结构；没有复制竞品美术，也没有将公开介绍当作实际试玩数据或市场排名证明。

## 个人造型相册

每关保留一个最佳已通过造型，记录物品、肤色和分数。低分重试不会覆盖更好的作品；同分可以更新搭配。玩家能查看大图、下载 1080×1920 画像或把作品重新穿上。

存档键仍是 `muse_bloom_save_v1`。旧存档保留成绩、衣橱、肤色与进度，不会凭空生成过去未保存的搭配；之后完成挑战即可补建作品。保存的分数会按已拥有物品重新校验。

## 人物与衣服兼容

这次保持 v1.1.1 的人物解剖、服装轮廓与配饰锚点。四种肤色、22 种发型、双手放松/握持姿势继续使用原始矢量材质。角色仍是可编辑的 2.5D SVG 插画。

手持包、托特包、团扇共享右手握持点 (486, 776)，第二件手持物镜像到左手 (234, 776)。完整握持手替换放松手，并覆盖提手；手表最后绘制。斜挎包使用肩部点 (299, 368)。卸下第一件后，剩余手持物会重新定位到右手。

`dev/accessory.test.js` 检查连接、遮挡与双手分配；`dev/ui.test.js` 保留 60 张已审阅的人物基准，本次没有更新基准。新整页布局和相册由 `dev/lookbook.test.js` 检查，并保留截图供人工审阅。

## 离线与素材

字体均使用本地系统字体；没有远程字体、图像、动画库或材质下载。人物实例的渐变、滤镜和裁剪 ID 独立命名，避免肤色串色。分享卡与宣传封面使用同一角色渲染代码，视频录制实际游戏操作。

运行 `npm run package:upload` 生成内嵌资源的 `dist/crazygames-upload/index.html`；它是当前 CrazyGames 文件上传入口的推荐产物。
