# Glow Studio · v1.1.0

本次采用冰蓝、淡紫、樱花粉与珍珠光泽，作为 Muse Bloom 的新视觉方向。它是一种具体的设计选择，不代表所有年轻女性都有相同审美。

## 视觉语言

- 本地无衬线粗体标题、清晰的卡片层次、圆角胶囊分类、渐变按钮和明确的选中状态。
- 试衣间使用柔光背景、珍珠球、轨道线、星芒与椭圆台座。背景装饰不拦截输入，不遮挡配饰握持区域。
- 星芒以 4 秒缓慢明暗变化；系统开启减少动态效果后关闭动画，按钮扫光也关闭。
- 四种肤色保留原有比例与服装坐标，通过皮肤径向明暗、柔和的肢体高光、发丝高光、布料渐变和投影增加体积。仍然是可编辑的 2.5D SVG 插画。
- 首页、衣橱、章节、收藏、结算、弹窗、分享卡、封面和视频使用相同视觉语言。

设计参考了 Pinterest 官方 2026 趋势中的 [Cool Blue、Gimme Gummy 与 Extra Celestial](https://business.pinterest.com/en-gb/pdf/pinterest-predicts/2026-trend-report/)，以及 Canva 对 [2026 设计材质与表达方式](https://www.canva.com/newsroom/news/design-trends-2026/) 的讨论。没有下载或复制这些来源的图像素材。

## 包与手的关系

手持包、托特包、团扇共享右手握持点 (486, 776)，第二件手持物镜像到左手 (234, 776)。包从手部向下悬挂，手指图层位于提手之前。斜挎包使用肩部点 (299, 368)，包体停在腰胯外侧。卸下配饰会同时移除相应手指叠层；剩下一件手持物会重新定位到右手。

`dev/accessory.test.js` 用实际 SVG 路径检查手与提手相交、手指覆盖握持点、前后顺序与双手分配。故意把包移开 40 px 必须失败。`dev/ui.test.js` 额外包含四种肤色的心形包、托特包、双手持物和斜挎包视觉基准。

## 可复现与离线

渐变 ID 由内容确定，界面每个人物实例再加独立命名空间，避免不同肤色人物互相引用渐变。分享卡和缩略图仍使用同一原始矢量资源。运行时没有远程字体、图像、动画库或材质下载。

## v1.1.1 人物细化

2026-10-19，按用户要求调整为欧洲少女时尚插画的角色方向：柔和椭圆脸、灰绿色眼睛与独立眼白/虹膜、细致鼻梁、自然唇形。四种肤色保留，发型和面饰的坐标兼容原衣橱。

双手重画为掌心、拇指与四根有长度差的手指。空手为放松姿势；提包时隐藏整只放松手，切换为完整握持手。前臂与手使用同一世界坐标光照，避免腕部出现手套般的色差。
