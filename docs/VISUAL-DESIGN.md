# Muse Bloom · Bedroom Studio · v1.3.0

2026-10-19：按用户提供的换装游戏截图调整视觉，再根据用户补充将场景改为家中卧室。采用棕色大眼睛的卡通少女、粉白界面、柔和高光、彩色分类图标与圆角衣橱卡片。原有杂志风格被本版替代。

## 场景与界面

原创卧室背景包括窗光、衣柜、梳妆台、床边与木地板，中央留给完整人物。桌面左右分栏，手机竖屏上下分区，横屏恢复左右结构。对话气泡展示当前搭配目标，肤色操作保持可见；衣橱独立滚动，提交按钮固定在其底部。

主要操作使用有柔和高光的粉色渐变按钮；分类图标具有独立服装颜色，选中分类以蓝色描边标识，选中服装显示粉色勾。控件继续保留文字、键盘焦点和 aria 状态。未加入没有功能的宠物或音乐入口。

背景由内置 imagegen 新建；参考截图只提供方向，没有复制其图像。提示词和资源路径见 SCENE-PROMPT.md。字体是本地系统字体，角色、服装和图标为原创 SVG。

## 人物与动态

重绘棕色虹膜、眼白、高光、眉眼、腮红与小笑容；头发补充细发丝。共享 720 × 1280 坐标保持不变。衣服、眼镜、耳饰和包沿用同一套锚点，四种肤色继续可选。手持包右手点 (486,776)、第二件左手点 (234,776)，斜挎肩部点 (299,368)。

眨眼约 5.8 秒一次，轻微呼吸和摇摆作用于整个合成人物；换装短暂放大并出现一次星光。分数页面按 S/A/其他通过/失败显示 3/2/1/0 星，分数规则仍为最高 94、35 分通过。照片导出保持静态、睁眼的完整造型。

Web Animations 用于换装、入场、奖励与星星，临时节点和动画会清理。系统减少动态效果会停用装饰动画；页面隐藏时取消瞬时效果并暂停持续动画。导出照片时的亮度变化很轻，不使用快速闪烁。

## 声音

九种原创 Web Audio 合成效果：点击、分类、穿上、脱下、清空、拍照、S 评价、普通评价、解锁。没有自动播放背景音乐；首个操作后才启动声音。全局静音持久化，设置里可试听。静音与隐藏页面会停止已排队音符；恢复时不补播。

## 兼容和验证

36 关、122 件服饰、相册、旧存档键 `muse_bloom_save_v1` 与评分规则保留。低分重试不会覆盖更好的作品，同分可更新造型。背景内嵌为数据 URI，离线试玩、导出卡片和单文件门户上传使用同一份资源。

人物基准包含 48 张全身与 12 张五官/手部近景，因本次重绘已审阅更新。`test:experience` 增加真实音频输出和动态生命周期测试。具体执行结果和平台验证边界见 QA.md；整页截图用于人工审阅，不冒充自动像素基准。
