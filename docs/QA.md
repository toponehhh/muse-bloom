## v1.0.0 性能样本（历史数据）

Edge 155，375×667，冷缓存，150 ms 延迟，1.6 Mbps 下行，4 倍 CPU 降速，本地 gzip 静态服务：

- 首次内容绘制：848 ms。
- DOM 与启动脚本完成：993 ms。
- 初始 HTTP 资源传输量：39,771 bytes（约 38.8 KiB）。
- 上述减速环境观察到一次 194 ms 启动长任务。
- 恢复正常 CPU 后，实际分类切换未观察到超过 50 ms 的长任务。

这是此前 v1.0.0 的一次本机模拟结果，本次贴合修复没有重跑降速性能测量。它不是 v1.0.1 或全球网络、真机性能保证；“所有环境都没有超过 50 ms 的启动任务”尚未达到。正式托管的压缩、缓存和设备性能会改变结果。
