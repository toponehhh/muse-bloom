## v1.0.1 换装修复与新增回归

此前的流程测试验证了分类互斥和分数，未验证服装贴合、卸装时的图层连续性或缩略图裁切。本次按用户反馈新增视觉检查；新测试在原版本上复现了人物 DOM 被整体移除的失败。

- 修正长袖与手臂、背心腰线、连衣裙腰臀轮廓；底衣只在对应空槽出现，避免从外衣边缘露出。
- 人物改为一个同步渲染的 SVG，保留人物容器与基础图层。卸装显示有色基础背心、短裤和基础短发；基础造型不计分。
- 修正发髻、长袖、长裙、长靴、斜挎包的缩略图边界。保存卡片使用与屏幕相同的 SVG 合成。
- Edge / Chrome：122 件逐件真实点击穿脱、122 张缩略图边界、卸装后的完整像素复原均通过。
- 8 种代表搭配 × 4 肤色，共 32 张基准已检查；普通测试比较截图，未经显式更新不会接受新画面。画面与导出在同一 Canvas 后端逐字节一致。
- 4 个视口 × 正常/减少动态效果，各 24 次连续切换，共 192 个采样帧。人物可见、提交可达、无水平溢出。
- 故意隐藏基础人物时，像素断言正确失败；恢复后通过。单文件卸装后实际评分为 0，重新搭配仍正常。
- Edge / Chrome 完整 36 关流程复验通过：正常解锁、存档、分享、离线文件、iframe、存储异常及控制台检查。

新增命令为 `npm run test:ui`；说明见 `docs/UI-TESTS.md`。详细输出是 `artifacts/ui/ui-report-*.json`、32 张基准对比图和响应式截图。测试工具、基准截图及开发依赖不进入 CrazyGames 游戏包。

## v1.0.0 性能样本（历史数据）

Edge 155，375×667，冷缓存，150 ms 延迟，1.6 Mbps 下行，4 倍 CPU 降速，本地 gzip 静态服务：

- 首次内容绘制：848 ms。
- DOM 与启动脚本完成：993 ms。
- 初始 HTTP 资源传输量：39,771 bytes（约 38.8 KiB）。
- 上述减速环境观察到一次 194 ms 启动长任务。
- 恢复正常 CPU 后，实际分类切换未观察到超过 50 ms 的长任务。

这是此前 v1.0.0 的一次本机模拟结果，本次贴合修复没有重跑降速性能测量。它不是 v1.0.1 或全球网络、真机性能保证；“所有环境都没有超过 50 ms 的启动任务”尚未达到。正式托管的压缩、缓存和设备性能会改变结果。
