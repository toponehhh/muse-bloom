# Character assets: reference-guided generation

Mode: built-in `image_gen` tool, transparent_background=true. No external API script or API key. The original `stitch_western_teen_dress_up_game.zip` was read as visual reference and left unchanged.

Reference images: the cute pastel fashion doll (`full_body_cute_cartoon_stylized_fashion_doll_avatar_for_an_html5_teen_dress_up/screen.png`), black-bob fashion doll (`full_body_fashion_doll_avatar_mannequin_of_a_stylish_east_asian_teen_girl_for/screen.png`) and curly-puff fashion doll (`full_body_cute_stylized_fashion_avatar_mannequin_of_a_sweet_black_teen_girl/screen.png`). All were visually inspected before use.

Modest opaque lavender athletic tank and matching fitted bike shorts; barefoot, no accessories. Compact healthy proportions about 5.5 heads tall. Full silhouette in a 2:3 portrait canvas. Keep alpha around hair, fingers, body and between legs. The tool preview displays RGB under transparency, so actual RGBA pixels were checked before delivery.
3. Mika identity edit: use Bella as the exact full-body sprite template, preserve canvas, body silhouette and joint positions, feet, hands and lavender outfit. Change identity to a youthful East Asian young adult woman age 19 with warm ivory complexion, large almond-shaped brown eyes, soft smile, jet-black bob and airy straight bangs. Use the supplied bob illustration as identity/style inspiration while keeping the same painted doll style and transparent background.
4. Zoe identity edit: use Bella as the same full-body template; preserve body pose, proportions, garment and hand/foot coordinates. Change identity to a youthful Black young adult woman age 19 with warm brown complexion, large hazel-brown eyes, friendly smile and textured curls in two high puff buns, inspired by the supplied curly-puff illustration. Output files are enumerated in `CHARACTER-ASSETS.json`. Only delivery resize/encoding was performed with Sharp (1024 × 1536 PNG to 768 × 1152 WebP, quality 92, alphaQuality 100); character painting and alpha editing used image_gen. Clothes and hair details remain authored SVG code.
