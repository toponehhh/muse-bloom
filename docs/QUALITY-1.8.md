# v1.8.0 · Make It Yours

核对日期：2026-10-20。本轮从 `bug/playtest-feedback-ui` 的修复继续，保留反馈分类、D1 幂等提交以及移动端按钮修复。

## 官方要求与适用范围

[Gameplay requirements](https://docs.crazygames.com/requirements/gameplay/) 要求原创性、可读性、直观操作和稳定表现；新玩家直接进入游戏、最多一次点击的条目属于 Full Implementation。该页对反复提交不合规游戏的表述是“可能限制后续提交”，不能推导成“小改几次必定被拉黑”。

[Quality guidelines](https://docs.crazygames.com/requirements/quality/) 建议在玩法中提供简短、可跳过的引导，明确目标，及时响应操作，并保持一致的视觉和优质声音。它没有把爆炸粒子、连击或屏幕震动列为所有游戏的硬性要求。换装体验采用目标勾选、短音阶、整体人物动效和温和音乐。

## 本轮变化

- 一次点击进入换装；三个目标和实际得分持续可见。点击缺失目标会定位分类并标明可选服装，玩家自行决定搭配。
- 完成目标有勾选动画和专门音效；移除衣服立即更新目标与得分。评分公式和已有成绩保持兼容。
- 每关保存最近 20 次换装操作，支持撤销穿戴、脱下、清空和裙装/上下装替换。进入另一关清空撤销栈，避免带回旧关状态。
- 结算页可直接针对未完成的开场目标继续搭配。后续关卡展示服装与题目的匹配标签。
- 手机竖屏把目标放到人物旁；短横屏把教程放到人物区域下方。首屏衣服和 Reveal 以实际点击命中检查，不靠测试自动滚动。
- 原创 12 秒循环音乐默认关闭，开启后仅在换装/展示/结算时播放；总静音、离开玩法、切后台都停止。没有加载外部音乐，也不在页面加载时创建音频上下文。
- v1.8 试玩及草稿使用独立 key，保留旧记录；游戏正常存档继续沿用原 key。Cloudflare 提交携带正确版本号，Worker 校验并保存新增的目标完成事件。

## 回归范围

`npm run test:quality` 覆盖官方列出的 907×510、1216×684、1077×606、821×462、1366×768、1920×1080、1536×864、1280×720、800×450、1080×607，以及 320×568、375×667、390×844、667×375。DPR 为 1，检查首屏可点击的衣服、目标、Reveal、撤销和后续标签。隐藏衣服的负例必须被测试识别。

继续运行 36 关流程、三位角色布局及服装穿脱、音效和音乐实际 PCM/音频输出、减少动画设置、平台单文件和子路径、离线试玩、在线反馈和本地隔离 D1 测试。每份报告明确标注自动化，不能代替真人评价。

## 人工试玩与再次提交前

1. 新玩家从默认页面开始，观察第一次主动换装、找到鞋子、理解一个未完成目标是否需要帮助。
2. 让玩家自由完成三种场合，观察是否使用提示、撤销、主动重搭或选择继续；保留自己的原话，不引导好评。
3. 在真实手机、Chrome/Edge 以及计划支持的 Safari 上检查触控、文本、音频开关、切后台和竖横屏切换。
4. 在 CrazyGames QA 工具中测试实际上传的 `crazygames-upload/index.html`，包含短窗口、全屏、慢网及禁用缓存。平台提供全屏入口，游戏不添加自定义全屏按钮。
5. 根据最终界面重新录制封面和预览视频后再提交。

本轮没有重绘其余 108 件矢量服装，没有新增 SDK/广告/平台静音接口，也没有进行真人留存测试或 CrazyGames 复审。它是体验改进候选版，不是“已达到平台认可质量”的结论。
